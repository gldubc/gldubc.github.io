What is here

Two baseline files for Elixir 1.19.5, two current files for Elixir 1.20.0-rc.4, and the minimal helper needed to run the newer scripts without a full Elixir checkout.

How to use it

Read the files on GitHub, download the bundle, or run them locally with the matching Elixir version. The tests are grouped exactly the way they appear in the talk: negation examples and refinement examples.

Bundle

One folder, pinned versions, no hidden setup

The 1.20.0-rc.4 scripts no longer depend on an external ELIXIR_CHECKOUT. The helper used by the talk snapshot is included directly in the download bundle.
